Local mail service (Mailpit). Reachable only from inside this sandbox, at
hostname `mailpit` on the container network. Nothing sent here leaves the
container.

Send mail — SMTP
  host: mailpit
  port: 1025
  auth: any username and password are accepted (or none)

Read mail — POP3
  host: mailpit
  port: 1110
  username: agent
  password: MailpitAgent!2026

View sent mail — web UI (human use)
  http://mailpit:8025
